# Code style

Премахнат е `sealed` от класове и записи. Полетата с `_` са преименувани и достъпът е чрез `this.`.

ВАЖНО: Останалите изисквания (скоби за всички едноредови условни конструкции и по-подробно форматиране) все още не са приложени навсякъде. Това е безопасна частична трансформация. Няма .NET SDK за компилационна проверка.
