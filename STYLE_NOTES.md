# Code style

Use `RabbitRpcClient.cs` as the C# formatting reference:

- Use four spaces and opening braces on their own lines.
- Add braces around conditional and loop bodies.
- Separate fields and statements with blank lines; keep constructor assignments together.
- Keep method declarations and parameter lists on one line.
- Put fluent call chains on separate indented lines.
- Keep the namespace directly after the using directives, with a blank line before its first type.

The solution builds with the .NET 10 SDK.
